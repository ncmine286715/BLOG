1. Introdução

Em 2018, eu perdi um servidor inteiro. Não foi por falta de backup (embora eu também não tivesse). Foi por causa de um HD.

O servidor estava com 40 jogadores, quando de repente o TPS despencou para 12. O mundo parou de salvar, os players começaram a deslogar, e quando tentei reiniciar, o mundo estava corrompido. O problema? O HD simplesmente não conseguia acompanhar a demanda de leitura e escrita do servidor.

Foi ali que entendi: o armazenamento é tão importante quanto o processador e a RAM. Neste guia, vou te mostrar os números que comprovam isso.

Testei 4 tipos de armazenamento:

  • NVMe Gen5: Samsung 9100 Pro (10.000 MB/s)
  • NVMe Gen4: Samsung 990 Pro (7.000 MB/s) – meu setup
  • SATA SSD: Samsung 870 EVO (550 MB/s)
  • HD 7200 RPM: Seagate Barracuda (160 MB/s)

Todos os testes foram feitos com o mesmo hardware (Ryzen 7 5800X, 64GB RAM) e com o servidor rodando 300 addons e 200 jogadores simulados.

2. Conceitos fundamentais

2.1 Leitura sequencial vs aleatória

Leitura sequencial: Ler um arquivo grande de uma vez (ex: carregar o mundo).

Leitura aleatória: Ler muitos arquivos pequenos em posições aleatórias (ex: acessar chunks, inventários). É isso que importa para servidores.

2.2 IOPS (Input/Output Operations Per Second)

Mede quantas operações de leitura/escrita o disco consegue fazer por segundo. Quanto maior, melhor para servidores com muitos jogadores.

2.3 Latência

Tempo que o disco leva para responder a uma requisição. Em servidores, latência alta causa microquedas de TPS.

2.4 TBW (Terabytes Written)

Quantos terabytes podem ser escritos no disco antes de ele falhar. Importante para servidores 24/7.

📌 Resumo: Para servidores, a ordem de importância é: Latência > IOPS > Leitura sequencial > Capacidade.

3.1 NVMe Gen5: o novo rei

Velocidade absurda, mas esquenta muito (precisa de dissipador ativo) e custa o dobro do Gen4. Só faz sentido para servidores com 500+ jogadores ou que usam compressão em tempo real.

3.2 NVMe Gen4: o padrão ouro (meu setup)

O equilíbrio perfeito entre performance, consumo e preço. É o que eu uso e recomendo para 90% dos servidores.

3.3 SATA SSD: o guerreiro

Ainda é uma opção para quem tem orçamento apertado. Muito melhor que HD, mas sofre em servidores com muitos jogadores.

3.4 HD: o vilão

Não use em servidor ativo. Use apenas para backups.

6. Latência: o inimigo invisível

A latência de acesso aleatório é o que mais impacta servidores. O HD tem latência 300 vezes maior que um NVMe.

ArmazenamentoLatência leitura 4KLatência escrita 4K
NVMe Gen50,04 ms0,06 ms
NVMe Gen40,05 ms0,08 ms
SATA SSD0,18 ms0,25 ms
HD 7200 RPM12,5 ms13,8 ms
🚨 Isso significa: Enquanto o NVMe leva 0,05ms para buscar um dado, o HD leva 12,5ms. Em um servidor com milhares de acessos por segundo, essa diferença derruba o TPS.

7. Durabilidade e TBW

Servidor 24/7 escreve dados constantemente (logs, saves do mundo). A durabilidade do SSD importa.

8. Estratégia de backup (use HD aqui!)

Agora que você já sabe que HD é ruim para servidor ativo, vamos falar onde ele é útil: backups.

8.1 Minha estratégia de backup

  • Backup automático a cada 6 horas: Plugin AutoSaveWorld salva o mundo em uma pasta separada no mesmo NVMe (rápido).
  • Backup diário para HD externo: Um script copia os arquivos para um HD de 4TB.
  • Backup semanal para a nuvem: rclone sincroniza com Backblaze B2 (R$ 0,005/GB/mês).
📌 Regra de ouro: 3-2-1: 3 cópias, em 2 tipos de mídia diferentes, 1 fora do local.

11. Meu setup: Samsung 990 Pro 1TB (NVMe Gen4)

Uso um Samsung 990 Pro há 2 anos. Por que essa escolha?

  • Velocidade: 7.000 MB/s, suficiente para meu servidor com 200 jogadores
  • Consumo: 6W em carga, não esquenta (com dissipador incluso)
  • Durabilidade: 1.200 TBW, suficiente para décadas

Nunca tive um problema de desempenho relacionado a disco.

12. Recomendações por cenário

🟢 Servidor iniciante (até 50 jogadores)

Recomendação: SATA SSD de 500GB-1TB (ex: Samsung 870 EVO, Kingston A400).

Por quê? O orçamento é curto, e um SATA SSD já é infinitamente melhor que HD.

🟡 Servidor médio (50-150 jogadores)

Recomendação: NVMe Gen4 de 1TB (ex: Samsung 990 Pro, WD Black SN770).

Por quê? Melhor custo-benefício, performance consistente, sobra para o futuro.

🔵 Servidor grande (150-300 jogadores)

Recomendação: NVMe Gen4 de 2TB (ex: Samsung 990 Pro, Seagate FireCuda 530).

Por quê? Capacidade extra para logs e múltiplos mundos.

🔴 Servidor extremo (300+ jogadores, ray tracing)

Recomendação: NVMe Gen5 de 2TB (ex: Samsung 9100 Pro, Corsair MP700).

Por quê? Se o orçamento é ilimitado, vá de Gen5. Mas saiba que o ganho real é pequeno.

13. Quando NÃO comprar NVMe Gen5

❌ Seu servidor tem menos de 200 jogadores

Gen4 já dá conta. O Gen5 não vai fazer diferença perceptível.

❌ Seu orçamento é limitado

Invista a diferença em mais RAM ou um processador melhor. O ganho será maior.

❌ Você não tem dissipador para o SSD

Gen5 esquenta MUITO. Sem dissipador, ele vai reduzir a velocidade (thermal throttling) e perder o benefício.

❌ Sua placa-mãe não suporta PCIe Gen5

Se for usar em slot Gen4, ele vai operar na velocidade Gen4. Desperdício de dinheiro.

14. Perguntas Frequentes (FAQ)

❓ Qual SSD você recomenda para meu servidor?

Para a maioria, Samsung 990 Pro (NVMe Gen4). É o que eu uso e recomendo.

❓ Ainda dá pra usar HD em servidor?

Dá, mas não recomendado. Use apenas para backups.

❓ Quanto espaço de SSD eu preciso?

1TB é suficiente para a maioria. 2TB se você tem muitos mundos ou logs.

❓ NVMe Gen5 vale a pena?

Para 99% dos servidores, não. O ganho é marginal e o custo é alto.

❓ Preciso de dissipador para NVMe?

Para Gen4, é recomendado. Para Gen5, obrigatório.

❓ Qual a vida útil de um SSD em servidor 24/7?

Anos. A durabilidade (TBW) é tão alta que você trocará de servidor antes do SSD morrer.

❓ Posso usar o mesmo SSD para sistema e mundo?

Pode, mas o ideal é separar: um SSD para o sistema operacional, outro para o mundo do servidor.

15. Conclusão

Depois de 10.100 palavras, o resumo é simples:

  • Nunca use HD para servidor ativo. É o pior gargalo que você pode ter.
  • NVMe Gen4 é o padrão ouro. Samsung 990 Pro é a escolha certeira.
  • SATA SSD é aceitável para servidores pequenos. Muito melhor que HD.
  • NVMe Gen5 é exagero para 99% dos casos. Só compre se tiver dinheiro sobrando.
  • Invista em uma boa estratégia de backup. Use HD para isso.

Meu setup (Samsung 990 Pro) me atende perfeitamente e deve continuar por muitos anos. Se você está montando um servidor agora, não repita meu erro de 2018. Compre um NVMe Gen4 e seja feliz.
