❓ Perguntas Frequentes

Encontre respostas para as dúvidas mais comuns sobre Minecraft Bedrock, otimização de servidores, hardware e nossos artigos técnicos.

Q:

Qual a configuração mínima de hardware para um servidor Minecraft Bedrock com 50 jogadores?

Para 50 jogadores simultâneos, recomendamos: CPU com pelo menos 8 núcleos (Intel i7 ou AMD Ryzen 7), 16GB de RAM (sendo 8GB alocados para o servidor) e armazenamento SSD NVMe. O servidor Bedrock é menos exigente que o Java, mas addons e mundos grandes podem aumentar a demanda.

Q:

É possível rodar um servidor Bedrock no Linux?

Sim! O servidor dedicado do Minecraft Bedrock (BDS) tem versão oficial para Linux. Recomendamos Ubuntu Server 22.04 LTS ou superior. Veja nosso guia completo em Otimização de Servidores Bedrock no Linux.

Q:

Como configurar um firewall para proteger meu servidor?

Recomendamos usar iptables ou UFW no Linux. As portas padrão do Bedrock são 19132-19133 (UDP). Além disso, considere usar um proxy como o BDS Proxy para proteção adicional contra ataques DDoS.

Q:

Qual processador é melhor para Minecraft Bedrock: Intel ou AMD?

Ambos são excelentes. Para jogar, processadores com melhor desempenho single-core (como Intel Core i9-14900K ou AMD Ryzen 9 7950X3D) são ideais. Para servidores, AMD EPYC ou Intel Xeon com muitos núcleos e suporte a ECC são mais recomendados.

Q:

Vale a pena investir em RAM DDR5 para Minecraft?

Sim, especialmente se você usa addons pesados ou servidores com muitos jogadores. O DDR5 oferece maior largura de banda, o que reduz o tempo de carregamento de chunks. Veja nosso comparativo DDR5 vs CAMM2.

Q:

Qual placa de vídeo escolher para jogar com shaders e RTX?

Para Ray Tracing no Bedrock, recomendamos pelo menos uma NVIDIA RTX 3060 ou AMD Radeon RX 6600 XT. Para 4K com shaders pesados, uma RTX 4070 ou superior é ideal. Veja nosso guia RTX vs Radeon.

Q:

Preciso saber JavaScript para criar addons?

Sim! A Scripting API do Minecraft Bedrock utiliza JavaScript (ou TypeScript). Recomendamos ter conhecimentos básicos de programação e lógica. Confira nosso tutorial Scripting API para iniciantes.

Q:

Qual a diferença entre Behavior Packs e Resource Packs?

Behavior Packs alteram o comportamento do jogo (IA de mobs, regras, mecânicas). Resource Packs alteram a aparência (texturas, sons, modelos). Ambos podem ser usados juntos para criar experiências completas.

Q:

Como faço para depurar erros em meus scripts?

Use o console do jogo (F1) e o arquivo de log do servidor. A Scripting API também permite usar console.log() para depuração. Recomendamos o uso do Visual Studio Code com as extensões oficiais da Microsoft.

Q:

Meu jogo está com FPS baixo, o que fazer?

Primeiro, verifique se seus drivers estão atualizados. Reduza a distância de renderização nas configurações. Desative partículas e sombras se necessário. Em PCs mais fracos, use o modo de vídeo "Gráficos rápidos". Veja nosso guia de otimização.

Q:

O que é TPS e como monitorar?

TPS (Ticks Per Second) mede a performance do servidor. O ideal é 20 TPS. Valores abaixo indicam lag. Você pode monitorar com comandos como "status" no console do servidor ou usando addons de monitoramento.
